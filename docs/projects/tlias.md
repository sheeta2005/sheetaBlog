# Tlias 教学管理系统

Tlias 是跟随黑马课程学习的教学管理项目，围绕部门、员工、班级和学员管理展开，包含信息维护、分页查询、文件上传与数据统计等功能。

项目主要用于练习 Java Web 与 Spring Boot 开发，熟悉分层结构、接口设计和数据库操作。通过具体的管理业务，学习参数校验、条件查询与事务处理，积累后端项目开发的基础经验。

[查看项目仓库](https://github.com/sheeta2005/tlias)
