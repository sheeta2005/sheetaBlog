# 雪

我不太喜欢斯洛尔的冬。

像是要把人皮都给扒下来的凛风，漫天吹刮的大雪，以及不是结冰就是被雪被所掩埋的道路。

怎么想怎么糟糕。

啊，对了，还经常填不饱肚子。

还有的话...

趴伏潜藏在灌木丛中的那人让思绪飘飞，大概也只是为了让他不那么在意自己那已然被细雪浸透的长袍吧。

不过胸间隐约传来的，那贯彻心扉的寒冷让他不得不收回思绪，专心于自己眼前的东西。

隔着手套传来的刺冷之感，有别于雪与风，那是独属于钢铁的奇妙触感。

他的身前，是一杆无论枪管亦或是木托，都满是划痕，饱含岁月之感的猎枪。黝黑枪管并不怎么油亮，只是隐约反着寒光。

将眼睛抵在倍镜之上，缓缓吐息，看不见的温差凝结成具现化的白雾，飘飞向天空。

透过倍镜所看见的世界，并不会有多么光怪陆离。

只是很普通的，为冰雪所覆盖的森林罢了。

只是很普通的，立于这片雪被之上的猎物而已。

那是一只麋鹿。

身姿矫健的它屹立于雪被之上，那警觉的琥珀色眸孔扫视着四周，就如同扫视着自己的领地，颇具生命力的长角如古树的粗根般肆意蔓延生长。

他试着让早已摸上冰冷扳机的食指微微发力，可那僵硬的食指大概是因为冻久了，好一会儿才能有所动作。

他并不觉得杀戮有什么意思。

只是为了生存下去的话，就谁也别怪谁了。

直到食指终于有了足以扣动那剥夺生命的扳片的力量之时。

被雪花掩盖的木丛却是簌簌抖动，紧接着，一个小小的脑袋从其中探了出来。

一只麋鹿幼崽，毛发浅浅棕黄，混杂些许白色的胎毛，泛着柔和的光泽，脆弱得就像是被水浸湿过的面包。

尚且还是离了父母，就无法自立的年龄。

一瞬的心乱，食指竟是下意识地离开了扳机。

无意识的呼气，也是让作为猎物的对象察觉到了异常：即使相隔甚远，麋鹿却是准确看向了他

伴随着低沉的吼叫，麋鹿带着幼崽穿过树林。

没有试着调整枪身，也没有随便蒙一枪。

只是让猎物就那样逃跑。

他从雪被之上站起身来，身形并不高大，毕竟他也才十七岁，以后或许还会再长高点？前提当然是营养跟得上。

左手攥住枪管中段，右手从枪托底部绕过去，指尖勾住背带末端的卡扣，轻轻一挑，让那条磨得发亮的帆布背带从肩头滑到臂弯，稍微拍了拍卡扣处，确保枪托稳稳卡在腰之后，少年正准备离开，脑袋却是被一个手刀猛地击中。

“刚刚为什么不开枪？你能打中的吧？”

隔着兽皮面罩的，带着点无奈的，中年女人的嘶哑而沉闷的声音。

“呃...？”少年似乎暂时还没想好说辞，只是呆呆张嘴。

“或许...可以等幼崽再长大点...”

大脑一热随意作出的回复，但下一刻就连少年自己也意识到，这是不切实际的幻想。

裹得厚实的女人将视线顺着麋鹿离去的方向望去，那边的雪空要比这边更加灰暗。

“怎么可能长得大呢。”

“雪暴要不了一两周就会到达此处，连我们想要活下来都已经要拼上全力。”

意识到说再多也改变不了事实，女人抬眼看了看逐渐暗沉的雪空，还没有多晚，现在追上去应该还来得及。

以难以琢磨的目光看向自己身后这还稍显青涩的少年。

“...下次别那么心软了，继续追吧，凯尔。”

紧了紧背上的枪带，玛莎循着雪地上的蹄印向前走去。

“...哦。”

食指缓缓摩挲过枪的肩带，凯尔慢步跟上走在前方的玛莎。

雪被相较早上出发时要变得松软，脚陷下去的深度也增加不少，每次迈步都要更加费力。

冰冷如刀的寒气不断在肺里来返往复，刮得人生疼。

二人在这之后没有交流，就像他们背上的那块沉默的铁，或许是没有话题，或许是没有对话的力气。

于冰雪森原上行走的二人成了此处唯一的景观。

这里是雪国斯洛尔的边境。

他们是斯洛尔边远地区一个聚居地的猎手，为了筹集食物面对数周之后的风暴而出来狩猎。

凯尔今年十七岁，而作为他的监护人的玛莎已经年过四十。

二人并没有血缘关系，凯尔只是玛莎收养的孩子而已。

但在这收养的十几年岁月之间，凯尔也确实在玛莎的培养与训练之下，成为一位优秀的猎手。

而凯尔背上的猎枪，也同样是玛莎赠予他的礼物。

前方的玛莎忽然将手臂抬起，示意身后的凯尔停下。

没有对话，玛莎只是转头看着凯尔。

大概是找到了吧，这样想着，凯尔走到玛莎的身旁。

隔着几棵枯树与几个灌木丛之外的，是在这广袤雪原难以一见的山丘，而最引人注目的，则是坐落在那山丘之上的深色山洞。

两团黑影栖息在山洞之内，由于距离过于遥远，凯尔也看不清楚。不过，那若隐若现的蹄印却是一路延展向那个洞口。

玛莎斜眼睨视着凯尔。

“这次要打中啊。”

“嗯。”

凯尔点头，取下背上的猎枪，找好固定点，搭好了枪位。

这是玛莎教给他的，卧姿射击。

身体左侧着地，以左肘和身体左侧支撑身体，两肘外撑着地，枪托抵于肩窝，自然贴腮，通过倍镜进行瞄准射击，这样就不容易偏离目标。

长吸一口气，隔着倍镜所看见的目标略显熟悉。

确实是先前看见的那只麋鹿，证明的话，它身旁趴伏着的幼崽便是。

它们正蜷缩在那洞穴之中。

从北方吹来的雪一片一片打在倍镜之上，擦掉之后，世界变得没那么清晰，虽然不影响射击。

因为先前没能按下扳机，导致不必要的工作量，害他们又在雪地之中多走好十几分钟。

麋鹿母亲用散发着热气的舌头舔舐着幼崽的皮毛。

凯尔不太理解这样的行为，也不知道这样做的意义，这与他接下来要做的，也同样毫无关系。

现在的他，只要扣下扳机就行。

“听我说。”

食指悬于扳机上的时候，凯尔的耳旁突然传来玛莎的声音。

不慌不忙，不骄不躁。

枯哑，沉稳。让人心安的声音。

“如果有一天，我是说如果。”

“你向我开枪的话，能够拯救所有你认识的人。”

“不包括你？”

“不包括我。”

“那我不要开枪。”

凯尔的食指在扳机上反复摩挲。

“不开枪的话，所有人都会死。”

“包括你？”

“包括我，还包括你自己。”

玛莎不知何时取下背在身后的猎枪，端正姿态，熟练地将枪托带着重量抵在肩窝。

另一根沉默的枪管指向麋鹿。

“不会有...”

一声枪响，盖住了凯尔的话语。

受惊的雪鸟高飞向天空。

中弹的麋鹿发狂似地扭动着身躯，如不协调的木偶跳着不怎样精妙的踢踏舞，只是几秒过后，便躺在雪地之上。干哑凄厉的咆哮，像是让那幼崽快逃一般。

殷红血液散着热气滴落在皑皑白雪之中。受惊的幼崽却依旧不知所措，悲鸣着踱步。

凯尔于空中画圈的食指微微颤抖，随后下压。

又一声枪响。

二人的枪管微微发热，丝缕白烟飘散。

世界重归寂静，只是又一抹鲜艳的红在这苍白雪原之上悄然绽开。

凯尔舌尖微苦，咂咂嘴开口。

“你总问些奇怪的问题，不会有那种情况的，所以...”

玛莎只是用凯尔难以理解的目光，看向远方。

“那个时候，一定，向我开枪。”
