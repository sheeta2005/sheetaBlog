# 后端专栏

欢迎来到后端技术学习专栏，这里记录了我在后端开发过程中的学习笔记和实践经验。

## 一、基础知识与运行原理

| 模块 | 复习内容 | 建议顺序 |
| --- | --- | --- |
| [操作系统](./操作系统/) | 内核、进程、调度、内存、死锁与 IO | 先理解资源与执行模型 |
| [计算机网络](./计算机网络/) | TCP、HTTP、TLS、DNS 与完整请求链路 | 再理解数据如何传输 |
| [JVM 虚拟机](./Java基础相关/JVM虚拟机/) | 执行、内存、类加载、垃圾回收与诊断 | 回到 Java 运行时 |
| [Tomcat](./Tomcat/) | 容器架构、请求分发、线程池与排障 | 串起服务端请求链路 |

本批笔记按 8—10 月的复习顺序分散归档。页首“整理日期”用于笔记编排，修订日期与 Git 更新时间单独展示。
